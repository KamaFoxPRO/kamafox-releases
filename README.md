# KamaFox PRO — instaladores y actualizaciones

Aquí se publican los instaladores de KamaFox PRO para Windows 10/11 (64 bits). La app instalada consulta esta página para avisarte de versiones nuevas; descargarlas e instalarlas es siempre decisión tuya.

- Descarga: pestaña **Releases** → la versión más reciente → `KamaFox-<versión>-Setup.exe`.
- Cada versión incluye su huella SHA-256 y un aviso firmado (`update.json` + `update.json.sig`) que la app verifica antes de instalar.
- Este repositorio no contiene el código fuente.
